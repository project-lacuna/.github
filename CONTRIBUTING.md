# Contributing

Contributions to this repository are welcome, including forks, tooling, documentation improvements, and community-made resources, so long as they align with the repository standards and contribution guidelines.

>[!IMPORTANT]Repository content and trademark rights
> `LACUNA` is a trademark of Project Lacuna, LLC, and repository licenses do not grant brand-use rights. Please see [TRADEMARK.md](./TRADEMARK.md) for trademark guidelines and permitted use.

## Before you start

* Read the target repository README.
* Check for existing issues or discussions.
* For larger changes, open an issue first to align on scope.

## Pull requests

* Keep changes focused.
* Update docs when behavior changes.
* Add tests when practical.
* Use clear commit messages and PR descriptions.
