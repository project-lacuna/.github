# Contributing

Thank you for contributing to a Project Lacuna repository.

## Before contributing

- Read the repository's `README.md`, `POLICY.md`, and any local instructions.
- Follow the [Organization Repository Safety Standard](POLICY.md).
- Do not include secrets, personal data, customer material, or unredacted production records in commits, issues, pull requests, comments, or logs.
- Verify that third-party material is compatible with the repository's intended license and use.

## Change process

1. Create a focused branch for the change.
2. Keep commits understandable and scoped to one purpose where practical.
3. Run the repository's documented formatting, linting, test, and validation commands.
4. Open a pull request that explains the change, validation performed, and any security, data-handling, or compatibility impact.
5. Address review feedback before merge.

## Changes needing extra review

Request review from the appropriate owner before merging changes that affect:

- Authentication, authorization, secrets, or access control.
- CI/CD workflows, deployment, infrastructure, or permissions.
- Shared AI prompts, skills, tool permissions, or model integrations.
- Data collection, logging, retention, telemetry, or external sharing.
- Licensing, third-party dependencies, or imported datasets.

## AI-assisted contributions

AI-generated content is subject to the same review, licensing, testing, and security requirements as any other contribution. Do not submit generated text or code you do not understand well enough to review and maintain.
